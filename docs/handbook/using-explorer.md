# 使用浏览器

[返回手册首页](README.md)

## 打开正确入口

向网络运维方取得实际的浏览器 URL。局域网地址只供可到达该局域网的用户访问；公网域名或
映射端口由运维方配置。文档示例地址 `192.0.2.10` 不能直接使用，`127.0.0.1` 只指向访问者自己的机器。

网页能打开但数据加载失败时，先向运维方报告页面地址和失败时间。这可能是前端仍使用旧的 API
地址，或网关/索引服务尚未就绪；不需要为了浏览网页安装节点、开放节点 RPC 或导入私钥。

## 查询与理解结果

| 查看内容 | 操作与判断 |
| --- | --- |
| 区块 | 从区块列表或搜索进入，核对高度、哈希和交易列表 |
| 交易 | 使用完整交易哈希查询，核对上链区块、执行状态和实际 gas；查不到不等于交易必然未广播 |
| 地址 | 使用完整地址查询余额和已索引交易；节点和索引器未追平时可能有延迟 |
| 合约/Token | 查看已提供的读接口；当前部署不提供公开写入式合约验证流程 |

首节点尚未挖矿时，只有 genesis（高度 0），页面可能显示 genesis 或空区块列表，已上链交易列表为空。
这是正常等待状态。仅有空区块而没有交易时，交易列表同样为空。
网络开始出块后索引器会继续处理；需要时刷新页面。当前入口不承诺 WebSocket 实时推送。

“没有记录”和“请求超时/服务错误”不同。正常空链不应导致 genesis RPC 超时。
服务刚启动后索引器需要初始化；运维人员应比较节点高度、索引高度和错误日志，不能只凭容器 running 判断可用。

## 公共 RPC 与功能范围

公共 RPC 为浏览器 origin 后的 `/rpc`，网络元数据为 `/network.json`。使用钱包前先核对运维方
提供的网络资料，不从节点的 `8545/8546` 私有端口推导公共地址。
查询或操作都不需要向浏览器服务提供私钥、助记词或账户解锁权限。

网关允许受限的查询方法和用户自行签名后的交易提交；不开放 `admin`、`debug` 等私有管理接口。
本部署不跟踪完整的 pending 交易池；已广播未上链的交易未显示，不能单凭浏览器判断广播失败。
若提交超时，先按交易哈希核对状态，不能仅据超时重复提交。

USDB 奖励、总供应量及 fee 分配语义仍有独立验收范围，相关字段可能隐藏或未提供。
不要把第三方浏览器的以太坊展示假设当作已经确认的 USDB 经济数据。看到 `not_qualified`、
`not_run` 或“等待交易样本”时，它们表示尚未完成对应验收。

遇到问题，提供页面地址、查询类型、公开的区块/交易哈希、时间和错误提示即可；不提供钱包秘密。
