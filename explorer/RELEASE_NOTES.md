# USDB Explorer

独立浏览器与公共 RPC 发布包，不依赖 usdb-node 安装。支持外部上游历史查询、tracing 和广播端点，
外部或内置 Nginx、已有 HTTPS 证书、独立数据库备份与升级。

每个版本附带独立的一键安装脚本，内置安装包摘要；自动安装命令入口并保留已有配置和部署数据。

当前第三方镜像仅用于私有兼容性预览，尚未通过公网发布准入；请保持访问限制。
实际 archive 重放、重组恢复、SourceDAO 合约验证和钱包广播仍需独立验收。
部署与配置说明包含在包内 README.md。此发布不改变 USDB 网络身份，不需要重置节点数据。

首个独立版本沿用原配置、数据库和兼容命令，发版移至 buckyos/usdb-explorer；网络身份不变。
